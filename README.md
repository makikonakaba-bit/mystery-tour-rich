## ⑤工夫した点・こだわった点
- 行き先が決まるだけでなく、もう少しドキドキ感がほしくて、ビジネスクラスへのアップグレードのくじを足しました。
- 新しいことを増やすより、今まで学んだこと（Math.random、if、.html()、CSS）の復習が優先と思い、確かめながら作りました。
- 最初はくじの当選確率を10人に1人にしましたが、当たりが出るのを確かめるのが大変だったので、5人に1人に変えました。

## ⑥難しかった点・次回トライしたいこと（又は機能）
- かっこ（ } ）の閉じ忘れや、# の書き忘れなどの打ち間違いで、ボタンがまったく動かなくなったり、色が変わらなかったりしました。小さな1文字で、全体が動かなくなることを知りました。
- add → commit → push の手順が多く、push を忘れて「展示室（GitHub Pages）が変わらない」と迷いました。こまめに push する習慣をつけたいです。
- 次回は、フロー図を作ってみたいです。
